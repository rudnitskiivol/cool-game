# Романтические линии — концепт-пак

Пять взрослых героинь для игры **cool-game**. У каждой есть история, портрет, пять последовательных сцен сближения и кадр неудачной ветки.

| Героиня | Мир | История |
| --- | --- | --- |
| Аико, 27 | Современная Япония | [Аико](aiko/story.md) |
| Ника, 29 | Киберпанк-будущее | [Ника](nika-cyberpunk/story.md) |
| Марина, 46 | Повседневность | [Марина](marina/story.md) |
| Валерия, 31 | Профессиональный рестлинг | [Валерия](valeria/story.md) |
| Ева, 29 | Психологический триллер | [Ева](eva/story.md) |

В каждой папке: `portrait.png`, `01-meeting.png` — `05-love.png`, `06-fail.png` и `story.md`. Для использования в Vite изображения доступны по адресу `/romance-pack/<папка>/<файл>`.

Материалы подключены к игре: в главном меню нажмите **«♥ Истории · 5 героинь»**, выберите героиню и начните историю. Портреты используются в выборе персонажа и во время полётов, иллюстрации меняются по ходу сюжета. Киберпанк-Ника из папки `nika-cyberpunk` заменяет прежнюю условную Нику в режиме свиданий.

Каждая история содержит три полётных этапа, два выбора и три варианта финала. Ошибка в полёте снимает 5 очков доверия и позволяет повторить этап. Финал зависит от доверия: от 75 — хороший, от 45 — открытый, ниже — неудачный. Предательство в последнем выборе сразу ведёт к неудачной ветке. Выбранная героиня запоминается; при новом запуске истории её сюжет начинается заново.

Оригинальные PNG сохранены. Игра загружает уменьшенные WebP из `web/` (весь набор — около 4,4 МБ); они входят в офлайн-кэш установленной игры. Чтобы пересоздать их после замены исходных рисунков: `npm run art:prepare`. Затем `npm run build`. Сценарии адаптированы в `src/romance.js`, переходы и финалы проверяются командой `npm test`.

Сцена `eva/04-choice.png` использует тот же рисунок, что и портрет Евы: при создании отдельного кадра был достигнут лимит генерации изображений. Кадр неудачной ветки для Евы отдельный.
