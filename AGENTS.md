# Правила для ИИ-агентов

## Не удалять, не перемещать, не переименовывать

В `public/romance-pack/` идёт активная работа над артом и сюжетом.

- `public/romance-pack/<героиня>/*.png` — оригинальные иллюстрации (исходники для `npm run art:prepare`).
- `public/romance-pack/<героиня>/story.md` — истории героинь.
- `public/romance-pack/README.md`.

Эти файлы нельзя удалять, перемещать, переименовывать или «оптимизировать», даже если игра их не загружает или они увеличивают размер сборки. Любые изменения — только по прямой просьбе пользователя.

Сгенерированные WebP в `public/romance-pack/web/` пересоздаются командой `npm run art:prepare`.

## Проверка после изменений

Изменение не считается готовым, пока не прошли обе команды:

- `npm test` — unit-тесты (`node --test`, файлы `tests/*.test.js`).
- `npm run test:e2e` — Playwright в Chromium, телефон и десктоп (`e2e/*.spec.js`, Vite поднимается сам). Первый запуск на машине: `npx playwright install chromium`.

E2E падает на любой ошибке в консоли браузера. Не глушите ошибки и не ослабляйте тесты ради зелёного прогона — чините причину.

Если изменили раскладку меню или кнопок, обновите координаты `MENU` / `BACK` в `e2e/helpers.js`. Новый экран или режим — добавьте сценарий в `e2e/flow.spec.js`.

## Совместимость: чего не делать

Игра должна работать в старом Safari, приватном режиме и без звука (это проверяет `e2e/compat.spec.js`).

- Не вызывать `ctx.roundRect` напрямую — только `drawRoundedRect` из `src/draw.js`.
- Не обращаться к `localStorage` напрямую — только `readStorage` / `writeStorage` из `src/game.js`. Прочитанные значения проверять: там может быть мусор.
- Звук — только через `src/audio.js`; он обязан молча работать без Web Audio.
- Новые браузерные API (`navigator.*`, `matchMedia` и т.п.) — с проверкой наличия.

## Сложность

- Бесконечный режим: профиль `default` с `ramp: true`, скорость/зазор/шаг труб растут по `src/difficulty.js`.
- Сюжетные полёты: фиксированные параметры профиля героини из `src/flightProfiles.js`.

Скорость мира брать из `obstacles.getSpeed(score)`, а не из `profile.speed`.
